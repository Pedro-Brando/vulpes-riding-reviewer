# Vulpes Riding Reviewer 🦊🐴

Certified equestrian judging by a fox with no formal qualifications.

Drop in a riding video, set the judging severity, and let the fox review it. Every ride receives the same verdict, because the verdict was never in question.

## How it works

- Pick or drag in any video. It never leaves the browser — no upload, no server, no network request.
- Slide the severity from **Gentle** to **Olympic**. The fox notes it, considers it, and gently ignores it.
- Watch the scan: sweeping scanline, tracking boxes on posture, hooves, and vibes, live telemetry, and a rotating set of analysis quotes.
- Collect the rosette: **A+ for effort for my pookie :)**

## Running it

It is one static `index.html` with no build step and no dependencies.

```
open index.html
```

Or visit the GitHub Pages site.
