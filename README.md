# Vulpes Riding Reviewer 🤖🐴

**Mobile suit VULPES-01, evaluation type.** A custom-painted machine with no formal equestrian qualifications, repurposed as a riding judge.

Drop in a riding video, set the judging severity, and launch the unit. Every ride receives the same verdict, because the verdict was never in question.

## How it works

- Pick or drag in any video. It never leaves the browser — no upload, no server, no network request.
- Slide the severity from **Gentle** to **Olympic**. VULPES-01 logs it, considers it, and quietly overrides it.
- Launch: the twin-eye cameras light up, a scanline sweeps the footage, tracking boxes lock onto posture, hooves, and vibes, and the HUD ticks over live telemetry while the analysis quotes rotate.
- Collect the rosette: **A+ for effort for my pookie :)**

## Running it

One static `index.html`, no build step, no dependencies.

```
open index.html
```

Or visit the GitHub Pages site.
